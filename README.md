## 💻 Proyecto destacado

<h3>🏦 Bank Transfer App</h3>

<p>
Sistema bancario desarrollado con <strong>Python</strong> que implementa
un flujo de transferencias con autorización mediante PIN.
</p>

<p>
El sistema permite crear una transferencia, generar un PIN de seguridad,
mantener la operación pendiente y posteriormente autorizarla mediante
